    Periodic systems¤

    Kohn-Sham DFT of crystals with GTH pseudopotentials, in a Gaussian basis (at the Gamma point or on a k-mesh) or in plane waves. All three engines share the verbs: scf (or scf_pw), forces and stress. The guide is Periodic systems.

    Cells and grids¤

    dftax.pbc.cell.Cell ¤

    Atoms in a periodic cell with GTH pseudopotentials.

    Coordinates and lattice vectors (the rows of a) are stored in Bohr. spherical defaults to True: the GTH basis sets are defined, and used by PySCF and CP2K, with spherical harmonics.

    dftax.pbc.build.uniform(*, mesh: tuple[int, int, int] | None = None, cutoff: float | None = None, chunk: int | str | None = 'auto') -> Uniform ¤

    The uniform real-space grid of a cell: the quadrature of the XC energy and the grid of the FFT Hartree term.

    Parameters:

    Name Type Description Default
    mesh tuple[int, int, int] | None

    points along each lattice vector, (n1, n2, n3).

    		 None
    cutoff float | None

    instead of a mesh, the kinetic-energy cutoff (Hartree) of the plane waves the grid must hold; the mesh is the smallest FFT-friendly one that does.

    		 None
    chunk int | str | None

    "auto" (default) holds the AO values on the grid when they fit the device budget and otherwise recomputes them per chunk of points on every evaluation (O(chunk x nao) memory, slower); None forces the held values, an int streams with about that many points per chunk (whole blocks of the grid).

    		 'auto'
    Example 
    KS(cell, PBE(), grid=uniform(mesh=(33, 33, 33)))
KS(cell, PBE(), grid=uniform(cutoff=60.0))

    dftax.pbc.kpoints.kmesh(n1: int, n2: int, n3: int, shift=(0, 0, 0)) ¤

    A Gamma-centred Monkhorst-Pack mesh: fractional k-points (nk, 3) and weights (nk,) (see :func:dftax.pbc.pw.monkhorst_pack).

    Gaussian basis¤

    KS(cell, xc, grid=uniform(...)) builds the Gamma-point functional, which every molecular solver takes unchanged (scf, gdm, minimize).

    dftax.pbc.kpoints.kpoint_ks(cell, xc, *, grid, kpts) -> KPointKS ¤

    The k-point functional of a cell on the uniform(...) grid at kpts = (kfrac, weights) (see :func:kmesh), solved by :func:dftax.scf like the Gamma-point :class:~dftax.KS.

    dftax.pbc.kpoints.KPointKS ¤

    The Kohn-Sham functional of a cell at a k-mesh (closed shell).

    dftax.pbc.kpoints.scf_k(ks: KPointKS, *, smearing=None, e_tol=1e-10, d_tol=1e-07, max_iter=100, diis_space=8, verbose=False, lindep: float = 1e-08) -> KResult ¤

    SCF of a k-point cell: an insulator (the lowest nocc bands of every k doubly occupied) or, with smearing (a :func:~dftax.ks.scf.fermi spec or its width in Hartree), Fermi-Dirac occupations with one Fermi level; e_tot is then the free energy. lindep: the canonical-orthogonalization threshold (as PySCF's remove_linear_dep_). :func:dftax.scf calls this for a :class:KPointKS.

    Plane waves¤

    dftax.pbc.pw.basis.planewaves(ecut: float, *, mesh: tuple[int, int, int] | None = None) -> PlaneWaves ¤

    Plane waves up to the kinetic energy ecut (Hartree).

    Parameters:

    Name Type Description Default
    ecut float

    the wavefunction cutoff, |k + G|^2 / 2 <= ecut.

    		 required
    mesh tuple[int, int, int] | None

    the density mesh; default, the smallest FFT-friendly one holding 4 ecut (the density of two waves of ecut).

    		 None
    Example 
    res = scf_pw(cell, LDA(), planewaves(40.0))

    dftax.pbc.pw.solve.scf_pw(cell: Cell, xc: XCFunctional, pw: PlaneWaves, *, kpts: tuple | None = None, nbands: int | None = None, e_tol: float = 1e-09, smearing: FermiSpec | float | None = None, d_tol: float = 1e-06, max_iter: int = 100, mixing: float = 0.5, kerker: float | None = 1.5, n_iter: int = 4, seed: int = 0, model: PWModel | None = None, verbose: bool = False) -> PWResult ¤

    Self-consistent field of a cell in plane waves (closed shell, an insulator: the lowest nocc bands of every k doubly occupied; with smearing, Fermi-Dirac occupations with one Fermi level, and e_tot the free energy E - TS).

    Parameters:

    Name Type Description Default
    cell Cell

    the :class:~dftax.pbc.Cell (its Gaussian basis is unused).

    		 required
    xc XCFunctional

    the functional (LDA or GGA).

    		 required
    pw PlaneWaves

    the basis, :func:~dftax.pbc.pw.planewaves.

    		 required
    kpts tuple | None

    (kfrac, weights), as :func:~dftax.pbc.kmesh returns them (default: the Gamma point alone).

    		 None
    smearing FermiSpec | float | None

    a :func:~dftax.ks.scf.fermi spec, or its width (Hartree) as a float; None is the insulator fill.

    		 None
    nbands int | None

    bands per k (default: occupied plus a tenth, at least 4; with smearing a fifth, at least 8).

    		 None
    e_tol float

    convergence of the energy (Ha).

    		 1e-09
    d_tol float

    convergence of the density residual (electrons, ∫|ρ_out - ρ_in|).

    		 1e-06
    mixing float

    the Pulay step.

    		 0.5
    kerker float | None

    the Kerker wave vector (None: plain Pulay).

    		 1.5
    n_iter int

    eigensolver steps per SCF iteration.

    		 4
    model PWModel | None

    the plane-wave set of an earlier result (result.model) to keep, at this cell's atoms and lattice: finite differences at a fixed basis, which the stress is the derivative of.

    		 None

    Forces and stress¤

    dftax.forces(cell, xc, result, grid=...) takes a cell and the result of any engine; see cell_forces.

    dftax.pbc.derivatives.cell_forces(cell: Cell, xc: XCFunctional, result: KSResult | KResult | PWResult | tuple, *, grid: Uniform | None = None, spin: int | None = None) -> Float[Array, 'n_atom 3'] ¤

    Forces on the atoms of a cell, -dE/dR (Ha/Bohr), (n_atom, 3).

    Parameters:

    Name Type Description Default
    cell Cell

    the :class:~dftax.pbc.Cell of the energy calculation.

    		 required
    xc XCFunctional

    its functional.

    		 required
    result KSResult | KResult | PWResult | tuple

    the converged result of any engine: a :class:~dftax.ks.scf.KSResult (Gamma point, or the occupied coefficients per spin channel), a :class:~dftax.pbc.kpoints.KResult (k-points) or a :class:~dftax.pbc.pw.PWResult (plane waves, which needs no grid). Under smearing, the derivative of the free energy.

    		 required
    grid Uniform | None

    the uniform(...) grid of a Gaussian calculation.

    		 None
    spin int | None

    2S when it differs from the cell's (read from the result otherwise).

    		 None

    dftax.pbc.derivatives.stress(cell: Cell, xc: XCFunctional, result: KSResult | KResult | PWResult | tuple, *, grid: Uniform | None = None, spin: int | None = None) -> Float[Array, '3 3'] ¤

    Stress tensor of a cell, (1/Ω) ∂E/∂ε (Ha/Bohr^3), (3, 3).

    Arguments as :func:cell_forces. The strain moves the lattice vectors, the atoms (fixed fractional coordinates) and the grid points together; the plane-wave stress is that of a fixed plane-wave set.

    Example 
    res = scf(KS(cell, LDA(), grid=uniform(mesh=(33, 33, 33))))
sigma = stress(cell, LDA(), res, grid=uniform(mesh=(33, 33, 33)))
